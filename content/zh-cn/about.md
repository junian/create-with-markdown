欢迎使用 **With Markdown** —— 一种更简单的文档写作方式。
我们相信写作应当是简单、强大且私密的。因此我们在 Markdown 之上构建了
这款编辑器，让你专注于文字，而不是与工具栏较劲。

## 为什么选择 With Markdown？

大多数文字处理软件把你的内容藏在专有文件格式里。With Markdown
让作品保持为纯文本，你可以随时阅读、编辑和带走。

With Markdown 采用**本地优先**设计：你的文档、图片和所有个人数据
都留在它们该在的地方——你的设备上。没有云端存储，
没有数据挖掘，内容从不被传输。只有你和你的文字。

无论你在写书、学术论文、简历还是会议记录，
With Markdown 都为你提供真实的页面来写作，完成后导出干净的文件。

## 强大功能

别被它的简洁外表骗了——With Markdown 具备完整文字处理软件应有的功能：

- **任何文档**——在同一个编辑器中写书、论文、简历、报告和笔记
- **实时预览**——写作时即时查看分页、可直接打印的页面
- **多种导出格式**——导出为 PDF、HTML、Markdown 或 MS Word（DOCX）
- **页面控制**——A4 或 US Letter、页边距、行距、字体和主题色
- **数学与交叉引用**——使用 KaTeX 编写公式，并在章节之间建立链接
- **图片库**——上传图片并在 Markdown 中引用
- **自动分页**——内容像真实文档一样在页面间流动
- **深色模式**——在任何光线下都能舒适写作
- **离线可用**——支持 PWA，可离线使用

## 隐私与安全

我们非常重视你的隐私。以下是我们保护数据的方式：

- **本地存储**——所有文档内容和图片都存储在浏览器的 IndexedDB 中，绝不上传到我们的服务器
- **无需账号**——无需注册或登录即可立即开始写作
- **不收集数据（文档）**——你的文档内容和图片绝不会被收集或传输
- **开源**——完全透明的代码，你可以审计并参与贡献
- **数据属于你**——随时导出和备份文档，控制权始终在你手中

## 分析

当你使用托管在 [withmarkdown.com](https://withmarkdown.com/){target="_blank" rel="nofollow noopener noreferrer"} 的版本时，
我们使用 **Google Analytics** 和 **Cloudflare Web Analytics** 了解汇总的使用情况。
这有助于我们通过浏览量、活跃用户等信息改进应用。

**重要：** 你的文档内容、页面设置和上传的图片*绝不会*包含在分析事件中。
我们只收集假名化的技术信息，以帮助我们改进应用。
Google Analytics 以假名方式使用，不会向分析服务商传输任何文档内容。
使用托管版本即表示你同意我们的[隐私政策](./privacy/)。
